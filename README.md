This project is a scientific graphical calculator developed in C++ using the WinAPI framework.
Unlike a traditional calculator that only performs basic operations like addition, subtraction, multiplication, and division, this one supports most mathematical operations found in modern scientific calculators.

It includes advanced functions such as:

Trigonometric operations: sin, cos, tan

Power and root calculations

Parentheses and decimal numbers

Memory and storage features

What makes this calculator special is the AI-based error correction system that automatically detects and fixes input mistakes (for example, missing parentheses or wrong symbols) before performing the calculation.

The program provides a clean graphical interface, allowing users to perform complex calculations easily and accurately.
It’s an ongoing project where I continue improving its logic and adding more smart features over time.
